# Atlas — AP Human Geography Prep

Atlas is a responsive study dashboard for AP Human Geography. It includes unit
progress, a daily practice prompt, an exam countdown, and study-plan guidance.

## Open the site

```bash
npm start
```

Then visit [http://localhost:3000](http://localhost:3000). To use a different
port, set the `PORT` environment variable:

```bash
PORT=4173 npm start
```

The site has no install step or third-party runtime dependencies.
